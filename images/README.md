# Images Folder

This folder stores all charts and visualizations generated by the analysis scripts and notebooks.

## Generated Charts

| File | Chart Type | Description |
|------|-----------|-------------|
| `monthly_revenue_trend.png` | Line Chart | Monthly Revenue & Profit for 2024 |
| `category_revenue.png` | Bar + Pie | Revenue split by Product Category |
| `region_sales.png` | Horizontal Bar | Revenue & Profit by Region |
| `top_products.png` | Bar Chart | Top 10 Products by Revenue |
| `quarterly_segment.png` | Bar + Pie | Quarterly Revenue & Customer Segment |

## How to Generate
Run either:
```bash
python scripts/sales_analysis.py
```
Or execute all cells in `notebooks/Sales_Analysis.ipynb`

All images are auto-saved to this folder at 150 DPI.
