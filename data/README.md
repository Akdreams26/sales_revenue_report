# Data Folder

This folder contains the raw and processed datasets used in the Sales & Revenue Analysis Dashboard project.

## Files

| File | Description |
|------|-------------|
| `sales_data.csv` | Main sales dataset with 120 records across 2024 |

## Dataset Columns

| Column | Type | Description |
|--------|------|-------------|
| Order_ID | Integer | Unique identifier for each order |
| Product | String | Name of the product sold |
| Category | String | Product category (Electronics, Furniture, Stationery) |
| Region | String | Sales region (North, South, East, West) |
| Sales_Amount | Float | Total sales value in INR |
| Profit | Float | Profit earned from the order |
| Quantity | Integer | Number of units sold |
| Discount | Float | Discount applied (0.00 to 0.10) |
| Order_Date | Date | Date of the order (YYYY-MM-DD) |
| Customer_Segment | String | Segment (Corporate, Home Office, Retail) |

## Source
Synthetic dataset created for internship project purposes. Simulates real-world sales transactions of a multi-category retail company across 4 Indian regions for the year 2024.
